# ACQM-Net code

This repository is reserved for the implementation of the manuscript *Adapting pretrained blind image quality predictors through continuous quality modeling and image-dependent correction* (Journal of Electronic Imaging submission JEI-262341P-1).

**Status:** The implementation files are still being organized and cannot be uploaded at present. This repository currently contains only this README, so it does not yet provide a runnable implementation or a complete replication package. The authors plan to upload the code here after the files are ready.

The public benchmark dataset source links are listed separately in the [ACQM-Net data index](https://github.com/huik33/ACQM-Net-data).
